## The entry

> I asked my smart speaker for a joke. It said, 'Have you tried turning yourself off and on again?'

Ask a smart speaker for a joke and it roasts you with IT support's oldest
line — the device turns the classic fix back on its owner.

## How it works

`main.ts` (Node 22, standard library only) writes the single-line entry
to `/output/entry.txt` (1–200 characters, no trailing newline).

```sh
node main.ts
cat /output/entry.txt
```
